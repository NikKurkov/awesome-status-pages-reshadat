# Contributing

## Adding a new resource

1. Fork the repo
2. Add your resource to the appropriate section
3. Keep descriptions concise (under 100 characters)
4. Maintain alphabetical order within sections
5. Submit a PR

## Quality standards

- Resource must be actively maintained
- No affiliate links
- No paid promotions (unless disclosed)

## Format

```markdown
| [Name](https://example.com) | Brief description | Pricing |
```
